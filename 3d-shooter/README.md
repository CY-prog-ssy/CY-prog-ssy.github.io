# OPERATION IRONHOLD — 3d（旧版）

原单文件 HTML 游戏的模块化拆分版。

## 目录约定

- `js/core/`      引擎底座（工具、音频、渲染、光照、天气、特效）
- `js/world/`     地图与碰撞查询
- `js/entities/`  玩家 / 敌人 / 友军 / 无人机 / 炮塔 / 武器
- `js/systems/`   玩法系统（输入、射击、伤害、玩家更新）
- `js/ui/`        HUD 与商店
- `js/game/`      流程与波次
- `js/net/`       局域网联机（因为某种原因被删除）

## 脚本加载顺序

顺序在 `index.html` 中由 <script> 标签先后决定，**不能随意打乱**。
详见 index.html 内注释。

## 已知性能问题（后续逐步优化）

1. `blocked()` 线性遍历全部 colliders —— 计划改为空间网格
2. `hasLOS()` / `muzzleClear()` 每帧对 worldSolid 全量射线 —— 计划改为 BVH 或网格加速
3. `groundAt()` 每个敌人每帧一次射线 —— 计划加缓存 / 只在必要时检测
4. 阴影贴图 2048 固定不变 —— 计划根据 GPU 与距离做自适应
5. 后处理 bloom 4 次全屏采样 —— 计划降采样分层
